REQUESTY – API-NØKKEL OG PERSONVERN

1. Opprett konto og fyll på kreditter

Gå til https://app.requesty.ai, opprett en konto og åpne betalingsinnstillingene. Legg inn betalingsmåte og fyll på ønsket saldo.

2. Opprett en API-nøkkel

Åpne API Keys, velg Create New API Key, gi nøkkelen et navn og opprett den. Kopier nøkkelen med én gang, siden hele nøkkelen bare vises ved opprettelsen.

3. Slå av prompt- og svarlogging

Finn nøkkelen under API Keys, åpne innstillingene og sett Logging til Off. Da lagrer ikke Requesty innholdet i promptene eller svarene som sendes med denne nøkkelen.

4. Bruk nøkkelen i appen

Lim nøkkelen inn i feltet Requesty API key på forsiden. Åpne deretter transkripsjonsverktøyet, velg Requesty som leverandør for notatgenerering og velg ønsket modell.

5. Aktiver Zero Data Retention (ZDR)

Velg Compliance under Admin i venstremenyen hos Requesty. Finn Zero Data Retention, klikk Edit på samme rad og aktiver innstillingen. Dette slår av innholdslogging for alle eksisterende og fremtidige API-nøkler. Innstillingen er permanent; tidligere innholdslogger slettes ikke automatisk.

Personvern: Appen bruker utvalgte EU-modellruter uten datalagring hos modellleverandøren og uten bruk til modelltrening. Aktiver ZDR hos Requesty for å hindre at Requesty lagrer nye prompts og svar. Bruksstatistikk, som tokenantall og kostnader, er fortsatt tilgjengelig.
