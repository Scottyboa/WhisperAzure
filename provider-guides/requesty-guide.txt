REQUESTY – API KEY AND PRIVACY

1. Create an account and add credits

Go to https://app.requesty.ai, create an account and open the billing settings. Add a payment method and top up your desired balance.

2. Create an API key

Open API Keys, select Create New API Key, give the key a name and create it. Copy the key immediately, as the full key is only shown when it is created.

3. Turn off prompt and response logging

Find the key under API Keys, open its settings and set Logging to Off. Requesty will then not store the content of prompts or responses sent with this key.

4. Use the key in the app

Paste the key into the Requesty API key field on the front page. Then open the transcription tool, select Requesty as the note-generation provider and choose the desired model.

5. Enable Zero Data Retention (ZDR)

Select Compliance under Admin in Requesty’s left menu. Find Zero Data Retention, click Edit on that row and enable the setting. This disables content logging for all existing and future API keys. The setting is permanent; existing content logs are not automatically deleted.

Privacy: The app uses selected EU model routes with no provider-side data retention or use for model training. Enable ZDR in Requesty to prevent Requesty from storing new prompts and responses. Usage statistics, such as token counts and costs, remain available.
